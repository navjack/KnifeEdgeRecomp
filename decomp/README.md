# Reverse-engineering workspace

Everything here except this file and the two `*_addrs.txt` files is generated
and gitignored.

- `symbol_addrs.txt`, `reloc_addrs.txt` — hand-maintained hints fed to Splat.
  Splat overwrites its own discoveries but keeps what is written here, so this
  is where a confirmed name or relocation belongs.
- `knife-edge.candidate.syms.toml` — the unreviewed probe from
  `scripts/generate_candidate_symbols.sh`. Never promote it to `input/`
  without review.
- `../asm/`, `../assets/` — Splat's disassembly output, regenerated by
  `scripts/split_rom.sh`.
